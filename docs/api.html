List users

List users with pagination and optional username/email filter and account-status filter. Requires the super_user permission.

Authorizations:
BearerAuth
query Parameters
page
integer

Page (1-based, default 1)

size
integer

Page size (default 10)

q
string

Filter by username or email substring

status
string

Filter by status: active, disabled, suspended

Responses

http://localhost:8080/api/v1/users

Upload a profile photo. Accepts multipart form field "avatar"; only jpeg/png/webp up to 2MB. The file is staged and uploaded asynchronously by the avatar_upload workflow: a 202 means the upload was accepted, not stored. Re-fetch the profile to see it.
